

# 前端技术演变历史

> 主线：静态页面 → jQuery 时代 → MVVM 单页 SPA → 元框架 + 混合渲染 + AI 原生前端
> 
> 核心驱动力：浏览器能力升级、用户对交互体验的需求、工程复杂度持续上涨

## 一、萌芽期（1990–2004）静态网页时代

1993 浏览器诞生，HTML 诞生；1995 Brendan Eich 10 天写出 JavaScript。

- 技术：纯 HTML + CSS，JS 仅做简单弹窗、表单校验；服务端渲染（PHP/ASP/JSP 输出页面）
- 特点：页面由后端生成，刷新整页跳转；JS 是锦上添花，不是页面核心
- 痛点：复杂 DOM 操作原生 JS 写起来极其繁琐，跨浏览器兼容噩梦（IE6）

> 代表：静态官网、早期门户网站

## 二、库时代（2005–2012）jQuery 统治时代

2006 jQuery 发布，解决原生 JS 跨浏览器、DOM 操作痛点。

- 技术栈：jQuery + 插件；后端模板渲染为主，AJAX 局部刷新开始普及
- 标志性能力：AJAX，实现**局部刷新**，不用整页重载
- 特点：**命令式编程**，手动查询 DOM、增删节点、绑定事件；数据和 DOM 强耦合
- 痛点：业务复杂后代码难以维护；数据变更要手动改 DOM，大规模项目容易面条代码

> 同期配套：YUI、Prototype、ExtJS

## 三、MVVM & SPA 兴起（2013–2018）现代前端框架诞生

核心思想：**数据驱动，声明式渲染**，数据变化自动更新 DOM，不再手动操作 DOM。

1. 2010: Backbone.js（MV * 先驱）
2. 2013: AngularJS（Angular 1.x），MVVM，双向绑定，首次把 SPA 推向大规模商用
3. 2014: Vue 1.0 发布；React 发布（[[1-2 虚拟dom思想]] ）
4. 2015: Vue 2，React 生态爆发，Webpack 成为打包标配，**SPA（单页应用）** 大规模普及

✅ 时代特征

- 前端独立拆分，前后端分离：后端只输出 JSON 接口，前端负责渲染全部页面
- 虚拟 DOM 成为主流方案，解决频繁 DOM 操作性能问题
- 工程化：Webpack、Babel、ES6、npm 包生态成熟
    
    ❌ 痛点：SPA 首屏加载慢，JS 包体积大，白屏，SEO 差；水合（hydration）开销大

## 四、元框架爆发期（2019–2024）：反思 SPA，混合渲染时代

大家发现：**不是所有网站都适合纯 SPA**，于是出现两类路线：

1. **服务端组件路线：[[Nuxt]]、[[Next.js]]
    
    SSR / SSG / ISR（[[页面渲染方案]]） → 发展为 RSC、Nuxt 服务端组件。把部分组件放回服务端执行，减少前端 JS。
2. **岛屿架构：Astro、Marko**
    
    2019 岛屿架构理论提出，Astro 落地，默认输出静态 HTML，交互组件按需加载 JS。

> 关键词：**元框架 Meta Framework** 登场

不再是单纯 UI 库（Vue/React），而是整套应用方案：文件路由、多种渲染模式、API 路由、资源优化一站式搞定。
同期配套技术：Vite（替代 Webpack，极速冷启动）、TS 全面普及、Wasm 成熟。



**新响应式范式出现：Signals 细粒度响应式**

SolidJS 率先落地；Vue Vapor、Angular Signals、React Compiler 陆续跟进，开始**脱离虚拟 DOM**，精准追踪依赖。

## 五、前沿阶段（2025–至今）：边缘、端侧、AI 原生前端

当前正在发生的演进：

1. 渲染：混合渲染、[[流式html]]、边缘渲染（Cloudflare Workers/Vercel Edge）
2. 原生浏览器能力：WebGPU / WebNN，前端本地跑 AI 模型、Embedding
3. AI 原生交互：SSE 流式输出、Agent 状态编排、前端工具调用
4. 构建：Rust 构建工具（Rolldown、Biome），打包速度大幅提升
5. 框架方向：编译优先，尽可能把开销放到编译期，减少浏览器运行时代码

## 极简主线总结

`静态页面(整页刷新)` → `jQuery(AJAX局部刷新)` → `Vue/React SPA(数据驱动+虚拟DOM)` → `元框架(SSR/岛屿架构混合渲染)` → `细粒度响应式 + 边缘/端侧AI前端`

## 补充：关键概念演变对照表

|阶段|编程范式|渲染位置|代表产物|
|---|---|---|---|
|静态网页|命令式|服务端输出完整 HTML|HTML + 原生 JS|
|jQuery|命令式|后端模板，前端局部修改 DOM|jQuery|
|SPA|声明式，虚拟 DOM|浏览器渲染页面|Vue2 / React|
|元框架|编译优先，混合渲染|服务端 / 静态预生成 + 少量客户端交互|Next、Nuxt、Astro|
|新一代|细粒度响应式|服务 / 边缘 / 浏览器端侧协同|Vue Vapor、Solid、RSC、WebG|
