JS 模块化规范主要有 4 种：**CommonJS、AMD、CMD、ES Module**；UMD 是兼容方案，不属于独立规范。
- [[CommonJS规范]]：Node 早期规范（**不是浏览器**），==**同步加载**==，运行时解析依赖；
- AMD：[[RequireJS]] 是 AMD 规范最出名的实现，==浏览器异步模块==，依赖前置；
- CMD： [[SeaJS]] 是CMD规范的实现，==浏览器异步模块==，依赖就近；
- [[ES Modules规范]](ESM)：==ES6 原生规范==，静态导入，==现代浏览器和 Node 通用==，目前主流。
# JS 模块化规范总览




> 分两大类：**非原生（需要加载器 / 打包工具）**、**语言原生**

## 1. CommonJS（CJS）

- 适用场景：早期 Node.js 默认模块规范
- 核心 API：`require()` / `module.exports` / `exports`
- 加载特点：**同步加载**，==运行时解析依赖==

js

```
const utils = require('./utils')
module.exports = { hello: 1 }
```

- 局限：同步，**浏览器不能直接用**，需要 webpack 等打包
- 现状：Node 老项目大量存在；新项目推荐 ESM

## 2. AMD（Asynchronous Module Definition，异步模块定义）

- 适用场景：浏览器端异步模块
- 代表实现：**[[RequireJS]]**
- 核心 API：`define(依赖数组, factory)`
- 特点：**依赖前置，异步加载**，先加载全部依赖再执行模块

js

```
define(['jquery'], function($){})
```

## 3. CMD（Common Module Definition，通用模块定义）

- 适用场景：浏览器异步模块，阿里玉伯提出
- 代表实现：**[[SeaJS]]**
- 核心 API：`define(function(require,exports,module){...})`
- 特点：**依赖就近**，代码执行到`require`才加载模块（懒加载思想）

js

```
define(function(require){
  const $ = require('jquery')
})
```

> AMD / CMD 都是为了解决浏览器异步模块，现在基本淘汰，只在老旧项目能见到

## 4. ES Module（ESM / ES6 Module）⭐现代标准

- JS **语言原生模块化规范**，ES2015 推出
- 适用：==现代浏览器 + Node.js==
- 核心 API：`import` / `export`
- 特点：**静态模块**，`import`只能写顶层，==编译期就能分析依赖==。[[Tree-Shaking]]的基础

js

```
import { foo } from './a.js'
export const foo = 1
```

浏览器使用：`<script type="module">`

Node：`package.json` 设置 `"type":"module"`

# 补充区分

1. UMD（Universal Module Definition）

> **不是独立规范**，是一段兼容代码，让模块同时支持 CommonJS、AMD、全局变量，用来写通用库（jquery/lodash 旧版本）
> 
> 目的：一份代码，Node、RequireJS、直接 script 引入都能用

# 快速对比

| 规范       | 环境         | 加载  | 依赖解析时机   | 是否原生        |
| -------- | ---------- | --- | -------- | ----------- |
| CommonJS | Node 旧版    | 同步  | 运行时      | ❌ Node 实现   |
| AMD      | 浏览器        | 异步  | 前置，提前加载  | ❌ RequireJS |
| CMD      | 浏览器        | 异步  | 就近，用到才加载 | ❌ SeaJS     |
| ESM      | 浏览器 + Node | 异步  | 编译期静态解析  | ✅ JS 原生     |
| UMD      | 通用兼容       | -   | 运行时      | ❌ 兼容包装方案    |
|          |            |     |          |             |
