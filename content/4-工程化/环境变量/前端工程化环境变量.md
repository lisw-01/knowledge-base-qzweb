> 核心一句话：**前端环境变量是【编译期注入】，打包时把变量值硬编码进 JS；靠 mode 匹配对应的 `.env.[mode]` 文件；只有约定前缀的变量，才能在业务代码读取。**

## 一、环境变量文件规范（Vite）

### 1. 文件命名规则（固定，不能随便起名）

plaintext

```
.env                # 所有环境都会加载，公共基础变量
.env.local          # 所有环境，本地私有，建议加入.gitignore，不要提交代码库
.env.development    # mode=development（npm run dev 默认）
.env.development.local
.env.production     # mode=production（npm run build 默认）
.env.production.local
.env.test           # 自定义mode，配合 vite --mode test
.env.test.local
```

✅ 加载优先级（后面加载的，同名变量覆盖前面）

`.env` < `.env.local` < `.env.[mode]` < `.env.[mode].local`

> `.local` 后缀：本地个人配置，**一定要写入 .gitignore**，不上传 git

gitignore

```
# .gitignore
.env.local
.env.*.local
```

### 2. 变量命名强制规则

**必须以 `VITE_` 开头，才能注入到 `import.meta.env`**

env

```
# .env.development
VITE_API_BASE = 'http://localhost:8081'
VITE_TITLE = '开发环境'

# 不带VITE_前缀，前端业务代码拿不到！仅vite.config.ts内可以读取
DB_PWD=123456
```

## 二、切换环境文件：修改 package.json 启动脚本（核心，更改读取哪个 env）

原理：`vite --mode xxx`，xxx 对应 `.env.xxx`

json

```
// package.json
{
  "scripts": {
    "dev": "vite", // 默认 mode=development → 读取 .env.development
    "dev:test": "vite --mode test", // mode=test → 读取 .env.test
    "build": "vite build", // mode=production → .env.production
    "build:test": "vite build --mode test" // 打包测试环境，读取.env.test
  }
}
```

执行命令示例

bash

```
npm run dev        # 开发环境
npm run dev:test   # 本地连接测试后端接口
npm run build:test # 打包测试环境产物
npm run build      # 打包生产
```

> ⚠️ Vite**不支持直接指定 env 文件名**，不能写 `vite --env-file .env.xxx`，只能用 mode 映射。

## 三、代码中使用环境变量（两处地方：业务代码 /vite.config.ts）

### ① Vue/TS 业务代码（页面、接口请求）

读取：`import.meta.env.变量名`

ts

```
// src/request.ts
const baseUrl = import.meta.env.VITE_API_BASE
console.log(import.meta.env.MODE) // 当前mode：development / test / production
console.log(import.meta.env.PROD) // boolean 是否生产环境
console.log(import.meta.env.DEV)  // boolean 是否开发环境
```

### ② vite.config.ts 配置文件内读取 env

需要手动引入 `loadEnv`

ts

```
import { defineConfig, loadEnv } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig(({ mode }) => {
  // 参数：mode, 项目根目录, 前缀过滤（空字符串代表读取全部变量，不限VITE_）
  const env = loadEnv(mode, process.cwd(), '')
  console.log('当前mode：', mode)
  console.log(env.VITE_API_BASE)

  return {
    plugins: [vue()],
    server: {
      port: env.VITE_PORT || 3000
    }
  }
})
```

## 四、其他前端框架简要对比（方便你统一认知）

### Vue-CLI（webpack）

- 前缀：`VUE_APP_`
- 读取：`process.env.VUE_APP_XXX`
- 脚本：`vue-cli-service serve --mode test`

### React CRA

- 前缀：`REACT_APP_`
- 读取：`process.env.REACT_APP_XXX`
- 脚本：`react-scripts start`

## 五、重要实操注意事项

1. **修改.env 文件后，必须重启 dev 服务！**
    
    vite 不会监听 env 文件，改完保存，Ctrl+C 停掉服务，重新执行`npm run dev`才生效。
    
2. 环境变量**打包固化**
    
    `npm run build` 之后，dist 里面 JS 直接写死变量值；**部署之后无法动态修改，改接口地址必须重新打包**
    

> 如果需求：打包后不用重打包、页面上线后动态切换接口地址 → 不能用环境变量，改用`public/config.json`，前端 fetch 异步加载配置。

3. ❌ 安全红线
    
    所有 `VITE_` 开头变量，打包后都在浏览器 F12 源码可见，**禁止放密钥、密码、token 私钥**。
