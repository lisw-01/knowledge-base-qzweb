### 关键经验（重要，后续复用）
1. **`slidep upsert-dsl` 的 `--page-index` 默认是 -1（追加）**。不传就会不断往后追加，造成重复页与错位。**每次必须显式传 0-based 页序**。
2. 一旦页序被写乱，CLI 没有删除页的命令。解决办法是 **`slidep create` 新建文件 + 按序全量 upsert 重建**，再替换主文件。
3. 全量重建 33 页时，一次性 for 循环会超时（SIGTERM），**要分批（≤8–9 页 / 批）或放后台跑**。
4. `CodeBlock` 必须显式加 `theme='github-dark'`，否则 Python/TS 代码块会渲染成近白底、语法色不可读。
5. `CodeBlock` 的 `width` 要比所在容器窄 20–30px，否则报 `child-containment right+Npx`。
6. VLM 视觉检查常报两类误判式问题：**BOTTOM_VOID / COLUMN_MISMATCH（过度留白）**。有效对策：
   - 给窄栏补一个"结构块"（如巨型数字对比、阶梯图）填满竖向空间；
   - 表格/列表的**最右侧列用右对齐徽标（badge）钉边**，避免右侧留白被判空洞；
   - 章节扉页若被判 BOTTOM_VOID，通常是底图亮度不够铺满——重新生成底图比改文案更有效。
7. FAIcon 可用名（FA6 free，已验证渲染成功）：`bolt` / `comment` / `comment-dots` / `layer-group` / `wrench` / `microchip` / `arrows-rotate` / `shield-halved` / `chart-line` / `box` / `unlock` / `compass` / `file-lines` / `puzzle-piece` / `code` / `key` / `lock` / `database` / `circle-check` / `bug` / `clone` / `circle-exclamation` / `ban`。
8. 生成式底图右下角会带「AI生成 WORKBUDDY」水印；把 `<Image>` 设为 `width:1536 height:1024` 且外层 `overflow:hidden`，水印会被裁到画布外（画布 1280×720）。
