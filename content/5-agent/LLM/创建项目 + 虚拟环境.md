> 虚拟环境：给这个项目单独一套 python 包，不和电脑其他项目互相干扰

### Windows cmd 操作

bash

```
# 进入你的项目文件夹，改成你自己的目录
cd D:\agent-study

# 创建虚拟环境，名字叫 venv
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate
```

激活成功：命令行前面会出现 `(venv)` 标识

### Mac 终端

bash

```
cd ~/agent-study
python3 -m venv venv
source venv/bin/activate
```

> 出现 `(venv)` 代表虚拟环境激活，**后续所有 pip 安装都要在激活状态下执行**

> 退出虚拟环境（不需要时）直接输入：

bash

```
deactivate
```
