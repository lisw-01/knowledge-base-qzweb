# DESIGN.md — 从 LLM 到 Agent 再到 Pi Agent

> 视觉设计宪法。逐页生成时严格对照；本文件未列出的 hex 不得出现在任何页面。
> 风格路线：**通用设计原则**（技术分享场景，未命中学术/咨询/红金政务分支）+ 用户显式指定「科技深色（深蓝底 + 青蓝高亮）」。

---

## 1. 画布与全局母版

- 画布：**1280 × 720**（16:9）
- 页面 padding：上下 `20`、左右 `72`
- 母版三区（内容页强制复刻，逐页位置一致）：

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px（含上 padding 20） | 左侧 4px 青蓝竖条 + 主标题 34px bold + 可选一行副标题 18px |
| **B · 内容区** | 120–660px | 540px 可用 | 一切正文、图表、代码、图示；禁止挤占 A/C |
| **C · 页脚条** | 660–720px | 60px（含下 padding 20） | 左：`从 LLM 到 Agent 再到 Pi Agent`（14px，40% 透明度）；右：`NN / 46`（14px） |

- 封面（01）/ 章节扉页（03·10·19·26）/ 结束页（33）采用**自定义版式**，可省略 C 区。
- 高度预算：`20(pad) + 100(A) + 12(gap) + 508(B) + 12(gap) + 40(C) + 20(pad) = 712 ≤ 720`。逐页按此核算，禁止溢出。

## 2. 颜色系统（4 个基准 hex + 其 alpha 变体）

| 角色 | hex | 用途 | 面积占比 |
| :--- | :--- | :--- | :--- |
| **BASE 深蓝底**（主色） | `#0B1220` | 页面背景、全幅底图蒙版基色 | ≤ 60% |
| **SURFACE 卡片面**（辅色） | `#16233D` | 卡片/分区底、代码块底、图表背景 | ≤ 30% |
| **ACCENT 青蓝高亮**（强调色） | `#2AD4EE` | 巨型数字、竖条、页码、图标、关键结论、数据系列 | ≤ 10%（Hero 页可至 20%） |
| **INK 浅色文本**（中性） | `#E8EEF9` | 标题与正文 | 剩余 |

**允许的 alpha 变体（同 hex 派生，不额外占用色位）**

| 用途 | 值 |
| :--- | :--- |
| 次级正文 | `rgba(232,238,249,0.62)` |
| 弱化文本 / 页脚 | `rgba(232,238,249,0.42)` |
| 卡片描边 | `rgba(42,212,238,0.22)` |
| 强调底纹（徽标/标签底） | `rgba(42,212,238,0.10)` |
| 分隔线 | `rgba(232,238,249,0.12)` |
| 背景蒙版 | `rgba(11,18,32,0.72)` |

**渐变方案（仅用池内色）**

- 页面底：`linear-gradient(160deg, #0B1220 0%, #16233D 100%)`
- 强调条 / 徽标：`linear-gradient(135deg, #2AD4EE 0%, #16233D 100%)`
- 全幅底图蒙版：图片上叠 `linear-gradient(90deg, rgba(11,18,32,0.94) 0%, rgba(11,18,32,0.45) 100%)`，保证浅色文字可读

**色彩节奏**

- Hero 页（01/11/15/21/23/28/33）：强调色 15–20%，可出现大面积光晕底纹。
- Supporting 页：强调色 ≤ 6%，强调色只出现在巨型数字、竖条、图标、结论句上。
- 至少 2 页色彩比例与全篇显著不同（21 页数字爆发、28 页路由图）。

**禁忌**：任何未列出的 hex；高饱和撞色铺满 ≥ 1/3 页面；每页色彩比例雷同。

## 3. 字体系统（2 套家族）

| 家族 | 字体栈 | 用在哪 |
| :--- | :--- | :--- |
| **正文家族** | `"Source Han Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif` | 标题、正文、表格、卡片 |
| **等宽家族** | `"JetBrains Mono", "Cascadia Mono", Consolas, monospace` | 巨型数字、代码块、命令、包名、指标码 |

**字号阶梯**

| 层级 | 字号 / 字重 / 行高 | 用途 |
| :--- | :--- | :--- |
| 封面主标题 | 84px / bold / 1.15 | 仅 01 |
| 章节大字 | 72px / bold / 1.1 | 03·10·19·26 |
| 巨型锚点数字 | 120px（主）/ 96px（次）/ 72px | 11·15·21·28·32 |
| 页面主标题 | 34px / bold / 1.3 | 每页 A 区 |
| 页面副标题 | 18px / normal / 1.5 | A 区第二行 |
| 卡片小标题 | 24px / 600 / 1.4 | 卡片头 |
| 正文 | 21px / normal / 1.6 | 段落 |
| 小字 / 说明 | 17px / normal / 1.6 | 卡内说明、图注 |
| 结论句 | 20px / 600 / 1.5 | "判断"条 |
| 引文 | 20px / italic | 「」 |
| 页脚 / 页码 | 14px / normal | C 区 |
| 代码块 | 14–15px | CodeBlock |

**规则**：巨型数字一律用等宽家族 + ACCENT；标题与正文同家族靠字重/字号拉开层级；禁止所有页面只用系统默认无衬线。

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 图数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 主标+副标+主视觉 | 20 | 1 | ≥ 35% |
| 目录 | 4 条 + 引导句 | 80 | 0 | — |
| 内容页·单主题 | 标题+正文+主视觉 | 180 | 1 | ≥ 30% |
| 内容页·卡片组 | 标题+引导+N 卡 | 每卡 ≥ 100 | 0–N | — |
| 数据/图表页 | 标题+主图+洞察 | 80 | 1 | ≥ 50% |
| 章节扉页 | 大字+一句小标 | 30 | 1 | ≥ 40% |
| 结束页 | 金句+落款 | 20 | 1 | — |

- 默认留白上限：常规内容页 **≤ 35%**（封面/扉页/结束页/显式留白页不受限）。
- 容器填充率 ≥ 85%；卡片尾部元素（结论条/标签条）必须 `marginTop: 'auto'` 钉底。
- 同一行兄弟卡：标题块/正文块/结论条三段 y 轴等高，尾元素 y 差 ≤ 16px。
