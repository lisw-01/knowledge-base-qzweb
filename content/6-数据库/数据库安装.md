## 路线一
> Windows 系统

## 步骤 1：下载 MySQL8.0

官网下载：[https://dev.mysql.com/downloads/mysql/](https://dev.mysql.com/downloads/mysql/)

选择 Windows (x86, 64‑bit), ZIP Archive 版本（压缩包版，不用安装程序）。

## 步骤 2：解压

把压缩包解压到：`D:\mysql‑8.0.40‑winx64`

## 步骤 3：新建配置文件 `my.ini`

在 D:\mysql‑8.0.40‑winx64 新建文件 `my.ini`

ini

```
[mysqld]
basedir=D:\mysql-8.0.40-winx64
datadir=D:\mysql-8.0.40-winx64\data
port=3306
character-set-server=utf8mb4
default-storage-engine=InnoDB

[mysql]
default-character-set=utf8mb4
```

## 步骤 4：初始化 mysql（管理员打开 PowerShell）

powershell

```
cd D:\mysql-8.0.40-winx64\bin
.\mysqld --initialize-insecure
```

执行完成，会自动生成 `data` 文件夹。**没有输出报错就成功**。

## 步骤 5：启动 mysql 服务

powershell

```
.\mysqld --console
```

窗口不要关闭！这个窗口就是 mysql 服务。新开一个**新的 PowerShell 窗口继续下面操作**。

## 步骤 6：登录 mysql（root 空密码）

新窗口执行：

powershell

```
cd D:\mysql-8.0.40-winx64\bin
.\mysql -u root
```

## 步骤 7：执行 SQL，创建数据库、测试表、只读账号

复制全部粘贴回车执行

sql

```
CREATE DATABASE IF NOT EXISTS agent_demo DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE agent_demo;

DROP TABLE IF EXISTS orders;
CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY COMMENT '订单ID',
    order_time DATETIME NOT NULL COMMENT '下单时间',
    amount DECIMAL(10,2) NOT NULL COMMENT '订单金额',
    product_name VARCHAR(100) COMMENT '产品名称',
    customer_id INT COMMENT '客户ID'
);

INSERT INTO orders(order_time, amount, product_name, customer_id) VALUES
('2026-01-05 10:20:00', 120.50, '产品A', 101),
('2026-01-12 14:30:00', 230.00, '产品B', 102),
('2026-02-03 09:10:00', 99.90, '产品A', 103),
('2026-02-18 16:45:00', 340.00, '产品C', 101),
('2026-03-06 11:20:00', 180.00, '产品B', 105),
('2026-03-22 13:15:00', 260.50, '产品A', 104),
('2026-04-10 15:30:00', 410.00, '产品C', 102),
('2026-04-28 10:05:00', 150.00, '产品B', 106);

CREATE USER IF NOT EXISTS 'readonly'@'127.0.0.1' IDENTIFIED BY 'Read@123456';

```

查询验证数据：

sql

```
select * from orders;
```

看到 8 条数据，MySQL 数据库创建完成。

> ⚠️缺点：每次使用必须运行 `.\mysqld --console` 启动服务；关掉窗口数据库就停止。



## 路线二


# Docker 容器化安装 MySQL（Windows）

> 前提：电脑先安装 **Docker Desktop**，Windows 推荐用 WSL2 后端。
> 
> 优势：

1. 不用在本机安装 MySQL 程序，容器跑 MySQL，用完可以删掉；
2. 端口 3306 映射到本机，Node 程序像访问本地 MySQL 一样连接；
3. 数据可以持久化，容器删除数据不会丢；
4. 一键启动、一键销毁环境，做实验非常干净。

## 步骤 1：安装 Docker Desktop

1. 下载：[https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
2. 安装，安装时勾选 **Use WSL 2 instead of Hyper‑V**。
3. 安装完成启动 Docker Desktop，右下角 Docker 图标出现，代表服务启动完成。

> 第一次启动会自动安装 WSL2 组件，按照提示重启电脑。

打开 PowerShell，验证 docker 是否可用：

powershell

```
docker --version
```

输出版本号，代表 docker 就绪。

## 步骤 2：运行 MySQL8.0 容器（复制整条直接运行）

powershell

```
docker run -d `
  --name mysql-agent-demo `
  -p 3306:3306 `
  -e MYSQL_ROOT_PASSWORD=Root@123456 `
  -e MYSQL_DATABASE=agent_demo `
  -v mysql-agent-data:/var/lib/mysql `
  mysql:8.0
```

### 参数解释

- `--name mysql-agent-demo`：容器名字
- `-p 3306:3306`：把容器 3306 端口映射到本机 3306 端口，node 程序连接 `127.0.0.1:3306`
- `-e MYSQL_ROOT_PASSWORD=Root@123456` root 管理员密码
- `-e MYSQL_DATABASE=agent_demo` **容器启动自动创建数据库 agent_demo**
- `-v mysql-agent-data:/var/lib/mysql`：数据卷持久化，删掉容器数据还在
- `mysql:8.0` 使用 mysql8.0 镜像

执行完，查看容器是否在运行：

powershell

```
docker ps
```

看到 `mysql-agent-demo` 状态 `Up` 就是启动成功。

> 如果本机 3306 端口被占用，把端口改成 `-p 3307:3306`，后续连接端口写 3307。

## 步骤 3：进入容器内部 MySQL，执行建表、造测试数据、创建只读账号

powershell

```
docker exec -it mysql-agent-demo mysql -u root -pRoot@123456 agent_demo
```

> 直接进入 mysql 客户端，已经自动选好 `agent_demo` 库。

复制下面全部 SQL 粘贴回车执行：

sql

```
DROP TABLE IF EXISTS orders;
CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY COMMENT '订单ID',
    order_time DATETIME NOT NULL COMMENT '下单时间',
    amount DECIMAL(10,2) NOT NULL COMMENT '订单金额',
    product_name VARCHAR(100) COMMENT '产品名称',
    customer_id INT COMMENT '客户ID'
);

INSERT INTO orders(order_time, amount, product_name, customer_id) VALUES
('2026-01-05 10:20:00', 120.50, '产品A', 101),
('2026-01-12 14:30:00', 230.00, '产品B', 102),
('2026-02-03 09:10:00', 99.90, '产品A', 103),
('2026-02-18 16:45:00', 340.00, '产品C', 101),
('2026-03-06 11:20:00', 180.00, '产品B', 105),
('2026-03-22 13:15:00', 260.50, '产品A', 104),
('2026-04-10 15:30:00', 410.00, '产品C', 102),
('2026-04-28 10:05:00', 150.00, '产品B', 106);

-- 创建只读账号，给pi‑agent node程序使用
CREATE USER IF NOT EXISTS 'readonly'@'%' IDENTIFIED BY 'Read@123456';
GRANT SELECT ON agent_demo.* TO 'readonly'@'%';
FLUSH PRIVILEGES;
```

> ⚠️容器环境，账号 host 写成 `'%'`，允许来自容器外部本机访问；本地裸机 mysql 用 `127.0.0.1`。

### 验证数据

sql

```
SELECT * FROM orders;
```

出现 8 条订单数据，建表完成。输入 `exit` 退出 mysql。

## 步骤 4：Node 项目 .env 配置（连接 docker 里的 mysql）

env

```
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=readonly
MYSQL_PASSWORD=Read@123456
MYSQL_DATABASE=agent_demo

OPENAI_API_KEY=sk-你的智谱key
OPENAI_BASE_URL=https://open.bigmodel.cn/api/coding/paas/v4
```

> 连接代码继续使用之前写的 `mysql2/promise`、`safeQuery()` 函数，**代码完全不用改**，就像访问本地 MySQL。

## 常用 docker 管理命令（记下来）

powershell

```
# 停止mysql容器
docker stop mysql-agent-demo

# 启动
docker start mysql-agent-demo

# 删除容器（数据卷mysql-agent-data还在，数据不会丢）
docker rm mysql-agent-demo

# 彻底删掉全部数据（实验重置用）
docker volume rm mysql-agent-data
```

## 重要踩坑点

1. **连接报错 Access denied readonly**
    
    容器环境用户 host 是 `'%'`，不要写 `127.0.0.1`。上面 SQL 已经创建 `'readonly'@'%'`。
    
2. Docker Desktop 没启动，docker 命令全部报错。右下角看 docker 图标。
    
3. 端口 3306 冲突
    
    运行提示端口被占用：启动命令改成 `-p 3307:3306`，`.env` 里面 `MYSQL_PORT=3307`。
    
4. WSL2 网络偶尔异常
    
    重启 Docker Desktop。




## 数据可视化工具Dbeaver


1. 下载地址： https://dbeaver.io/download/
2. 连接数据库可能出现的问题 ：Public Key Retrieval is not allowed
# Public Key Retrieval is not allowed

> 原因：MySQL8.0 (Docker 版) 默认认证插件是 `caching_sha2_password`，DBeaver (JDBC 驱动) 默认禁止从服务端抓取公钥做密码加密，本地开发环境高频报错博客园。

> ⚠️`allowPublicKeyRetrieval=true` **只用于本地开发实验，生产环境不要开启**。

## 方案 1：DBeaver 修改驱动属性（最快，推荐）

1. 编辑你的 MySQL 连接 → 切换到 **驱动属性 (Driver properties)** 标签页GitHub
2. 新增 2 个属性：

|属性|值|
|---|---|
|`allowPublicKeyRetrieval`|`true`|
|`useSSL`|`false`|

3. 保存，点击测试连接，即可正常连上博客园。

## 方案 2：修改 MySQL 用户认证方式（更干净，推荐本地环境）

进入 docker mysql 容器执行：

powershell

```
docker exec -it mysql-agent-demo mysql -u root -pRoot@123456 agent_demo
```

执行 SQL，把 `root` 用户改成传统 `mysql_native_password` 认证，就不会报这个公钥错误：

sql

```
ALTER USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY 'Root@123456';
FLUSH PRIVILEGES;
```

执行完，DBeaver**不需要修改任何驱动参数**，直接就能连接成功。
